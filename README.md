# Number System Quiz Android App

A phone-friendly Android quiz app for a B.Ed pedagogy project.

## Build APK using only your phone

1. Create a GitHub repository and upload all files in this project.
2. Open the repository on GitHub and tap **Actions**.
3. Choose **Build Number System Quiz APK**.
4. Tap **Run workflow**.
5. Wait for the green check mark.
6. Open the completed workflow run and download the **NumberSystemQuiz-debug-apk** artifact.
7. Extract the downloaded ZIP and install `app-debug.apk` on your Android phone.

The workflow uses Java 17, Android SDK 35, Android Gradle Plugin 8.7.3, and Gradle 8.9.
